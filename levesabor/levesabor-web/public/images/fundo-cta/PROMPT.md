# P-11 — Padrão de fundo do CTA final da landing v2

**Onde é usada:** decorativo, atrás do `.ctaCard` na secção final da landing (`LandingPage.tsx`/`LandingPage.module.css`, classe `.ctaCard`, fundo `var(--tan)`) — opcional; a secção já funciona sem esta imagem (fundo sólido `--tan`).
**Ficheiro esperado nesta pasta:** `fundo-cta.svg` (preferido, para repetir/posicionar por CSS `background-image`) — arcos/curvas subtis, mesma família visual de `public/images/admin-banner`.

## Prompt para colar no ChatGPT

> Cria um padrão de fundo abstrato e subtil, com arcos concêntricos ou curvas orgânicas incompletas, no espírito de um "anel de progresso" desconstruído — decoração de baixo contraste, não deve competir com texto por cima.
>
> Cores: tons de terracota e âmbar (`#C43E1C`, `#E3A72E`) a ~10-15% de opacidade sobre fundo transparente, para poder ser colocado sobre o bege `#E7C9A0` (`--tan`) da secção sem ficar pesado.
>
> Formato: retangular, 1600×900 px, fundo transparente, elementos concentrados nos cantos/margens para não sobrepor o texto central.
>
> NÃO incluir: texto, ícones figurativos, pessoas — puramente abstrato/geométrico.
