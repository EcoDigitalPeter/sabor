Contexto:

* A cotação enviada ao cliente está neste link: https://claude.ai/code/artifact/ee590e77-6af4-4cbd-91ae-37e73af62e93?org=633b15d0-7e38-4243-b161-41ae03029084
* O objetivo é criar um plano end-to-end para que uma equipa técnica consiga desenvolver frontend, backend e base de dados com clareza.
* A base de dados será Supabase, mas apenas como PostgreSQL. Não devemos usar autenticação, storage, edge functions, realtime ou outros serviços proprietários do Supabase para evitar dependência da plataforma.
* O backend será em Java Spring Boot.
* O backend deve inspirar-se na arquitetura, estrutura e padrões do projeto local: `D:\Coding\irc-container`.
* O resultado principal deve ser um ou mais ficheiros `.md` bem organizados.

Tarefa:
Cria um plano completo de implementação da aplicação, dividido por tipo de utilizador/persona e suas funcionalidades.

Para cada tipo de utilizador, apresenta:

1. Nome do utilizador/persona.
2. Objetivo principal desse utilizador.
3. Lista de funcionalidades disponíveis para esse utilizador.
4. Para cada funcionalidade:

   * Descrição funcional.
   * Fluxo do utilizador.
   * Regras de negócio.
   * Tarefas de frontend.
   * Tarefas de backend.
   * Tarefas de base de dados.
   * APIs/endpoints necessários.
   * Validações.
   * Estados possíveis.
   * Critérios de aceitação.
   * Prioridade: MVP, Fase 2 ou Futuro.

Também quero que cries uma secção específica para UI/UX contendo:

1. Lista de telas necessárias.
2. Objetivo de cada tela.
3. Componentes principais de cada tela.

Regras importantes:

* Não assumir funcionalidades fora da cotação sem indicar claramente que são sugestões.
* Organizar tudo de forma prática para uma equipa técnica executar.
* Separar claramente MVP, Fase 2 e Futuro.
* Usar linguagem técnica clara.
* Evitar descrições genéricas.
* Sempre que possível, transformar funcionalidades em tarefas executáveis.
* Considerar que o frontend, backend e base de dados serão desenvolvidos por equipas diferentes, por isso cada responsabilidade deve estar bem separada.

Entrega esperada:
Um plano técnico completo, estruturado em Markdown, pronto para ser usado como base de desenvolvimento da aplicação.
